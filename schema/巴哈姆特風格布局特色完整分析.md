## 1. 整體品牌色彩系統

### 1.1 主色調 - 青綠色 (Teal)

巴哈姆特最顯著的視覺特徵就是其招牌的**青綠色**作為主要品牌色：

- **色值**: `#17a2b8` (Bootstrap 的 `info` 色系)
- **使用場景**:
  - 頂部導航列背景色
  - 主要操作按鈕 (確認、送出、登入等)
  - 連結文字的 hover 狀態
  - 選中狀態的標籤頁底線
  - 重要資訊的強調色

### 1.2 配色方案

**背景色階**:
- 主背景: `#ffffff` (純白)
- 次要背景: `#f8f9fa` (極淺灰，用於區分區塊)
- 卡片背景: `#ffffff` with `box-shadow`
- Hover 背景: `#f1f3f5` (淺灰)

**文字色階**:
- 主標題: `#212529` (深灰黑)
- 內文: `#495057` (中灰)
- 次要文字: `#6c757d` (淺灰)
- 禁用狀態: `#adb5bd` (更淺灰)

**狀態色**:
- 成功: `#28a745` (綠色)
- 警告: `#ffc107` (黃色)
- 錯誤: `#dc3545` (紅色)
- 資訊: `#17a2b8` (青綠色，與主色相同)

**邊框色**:
- 預設邊框: `#dee2e6` (淺灰)
- 表單輸入框: `#ced4da`
- Focus 狀態: `#80bdff` (淺藍色光暈)

### 1.3 色彩使用原則

1. **高對比度**: 白色背景搭配青綠色按鈕，確保視覺清晰
2. **色彩克制**: 除主色外，大量使用白色與灰階，避免視覺疲勞
3. **語意化用色**: 綠色表成功、紅色表錯誤，符合用戶直覺
4. **品牌一致性**: 青綠色貫穿所有介面，強化品牌記憶點

## 2. 頂部導航列架構

### 2.1 Layout 結構

**高度**: 固定 `56px` (與 Bootstrap navbar 預設一致)

**結構分層**:
```
┌─────────────────────────────────────────────────────────┐
│ [Logo]  [導航項目]                    [搜尋] [用戶] [通知] │
└─────────────────────────────────────────────────────────┘
```

### 2.2 詳細元件配置

**左側區域**:
- **Logo**: 白色 logo 圖示，尺寸約 40×40px，左邊距 `16px`
- **導航項目**:
  - 項目間距: `24px`
  - 字體顏色: `rgba(255, 255, 255, 0.9)`
  - Hover 狀態: `rgba(255, 255, 255, 1)` + 底部 2px 白色底線
  - 活動項目: 底部 3px 白色底線

**右側區域**:
- **搜尋框**:
  - 寬度: `200px` → 展開至 `300px` (on focus)
  - 背景: `rgba(255, 255, 255, 0.2)`
  - 邊框: 無，使用背景色區分
  - Placeholder: `rgba(255, 255, 255, 0.6)`
  - 圖示: 放大鏡 icon，白色

- **通知鈴鐺**:
  - 圖示大小: `20px`
  - 未讀徽章: 紅色圓點或數字 badge
  - 位置: 右上角 offset

- **用戶頭像 Dropdown**:
  - 頭像尺寸: `32px` 圓形
  - Dropdown 寬度: `220px`
  - 項目: 個人資料、設定、登出等
  - Dropdown 背景: 白色，帶陰影

### 2.3 固定定位 (Fixed Positioning)

- `position: fixed`
- `top: 0`
- `left: 0`
- `right: 0`
- `z-index: 1030` (高於大部分內容)
- 下方內容需預留 `padding-top: 56px`

### 2.4 響應式行為

**桌面 (≥992px)**:
- 完整顯示所有導航項目
- 搜尋框可見

**平板 (768px - 991px)**:
- 隱藏次要導航項目
- 搜尋框保持可見
- Logo 與用戶區域保持

**手機 (<768px)**:
- 漢堡選單 (≡) 出現於左側
- Logo 居中
- 僅顯示用戶頭像與通知
- 搜尋框移至展開選單內

## 3. 模態對話框設計模式

### 3.1 基本結構

巴哈姆特大量使用**模態對話框 (Modal)** 處理關鍵操作，避免頁面跳轉：

**尺寸規範**:
- 小型 Modal: `400px` 寬 (登入、確認)
- 中型 Modal: `600px` 寬 (序號兌換)
- 大型 Modal: `800px` 寬 (詳細資訊)
- 響應式: 手機上為 `calc(100vw - 32px)`

### 3.2 Modal 組成元件

**1. 遮罩層 (Backdrop)**:
- 背景色: `rgba(0, 0, 0, 0.5)`
- 點擊遮罩關閉 Modal (可選)
- 動畫: `fade-in` 0.15s

**2. 標題列 (Header)**:
- 高度: `60px`
- 背景: 白色
- 底部邊框: `1px solid #dee2e6`
- 標題文字: `18px`, `font-weight: 600`, 左對齊，左邊距 `24px`
- 關閉按鈕: 右上角 ×，大小 `32px`，hover 變紅

**3. 內容區 (Body)**:
- Padding: `24px`
- 背景: 白色
- 最大高度: `calc(100vh - 200px)` 可滾動
- 內容靠左對齊

**4. 按鈕列 (Footer)**:
- 高度: `72px`
- 背景: `#f8f9fa` (淺灰背景)
- 上邊框: `1px solid #dee2e6`
- 按鈕排列: 右對齊
- 按鈕間距: `12px`
- 按鈕順序: [取消] [確定] (確定按鈕為青綠色)

### 3.3 常見 Modal 類型

**3.3.1 登入 Modal**

觀察到的特色：
- 使用**手機號碼 + 簡訊驗證碼**登入
- 輸入框間距: `16px`
- 「取得驗證碼」按鈕嵌入在輸入框右側
- 倒數計時顯示: "60秒後可重新發送"
- 底部包含「尚未註冊？」連結

範例流程：
```
1. 輸入手機號碼 (格式: 09XXXXXXXX)
2. 點擊「取得驗證碼」
3. 輸入 6 位數驗證碼 (範例: 712345)
4. 點擊「登入」
5. 成功 → 關閉 Modal，顯示成功訊息
```

**3.3.2 確認 Modal**

用於關鍵操作的二次確認：
- 標題: "確認要執行此操作嗎？"
- 內容: 簡短說明操作後果
- 圖示: 警告圖示 (⚠️) 居中顯示
- 按鈕: [取消 (預設)] [確定 (青綠色)]

**3.3.3 成功提示 Modal**

操作成功後的反饋：
- 綠色勾勾圖示 (✓) 居中
- 標題: "操作成功"
- 訊息: 簡短說明結果
- 單一按鈕: [確定]
- 3 秒後自動關閉 (可選)

**3.3.4 序號兌換 Modal**

詳細的多步驟操作：
- 步驟指示器: ① → ② → ③
- 輸入區: 序號輸入框 (placeholder: "請輸入序號")
- 驗證區: 顯示序號對應的獎勵內容
- 確認區: 最終確認兌換
- 結果顯示: 兌換成功後的詳細資訊

### 3.4 Modal 動畫效果

- **進入動畫**:
  - 遮罩 fade-in 150ms
  - Modal 從 `scale(0.9)` → `scale(1)` + fade-in 200ms
  - 使用 `cubic-bezier(0.4, 0, 0.2, 1)` 緩動

- **退出動畫**:
  - Modal 從 `scale(1)` → `scale(0.95)` + fade-out 150ms
  - 遮罩 fade-out 200ms

### 3.5 Modal 使用原則

1. **避免嵌套**: 不在 Modal 內開啟另一個 Modal
2. **Esc 關閉**: 按 Esc 鍵應關閉 Modal (除非是強制確認)
3. **Focus trap**: Modal 開啟時，Tab 鍵循環僅在 Modal 內
4. **Scroll lock**: Modal 開啟時，背景頁面不可滾動

## 4. 表單設計規範

### 4.1 輸入框 (Input Fields)

**尺寸**:
- 高度: `40px` (標準)
- 大型: `48px`
- 小型: `32px`
- 寬度: 通常為 `100%` 容器寬度

**樣式**:
- 邊框: `1px solid #ced4da`
- 圓角: `4px`
- Padding: `8px 12px`
- 字體大小: `14px`
- Placeholder 顏色: `#6c757d`

**狀態樣式**:

**Focus 狀態**:
```css
border-color: #80bdff;
box-shadow: 0 0 0 0.2rem rgba(23, 162, 184, 0.25);
outline: none;
```

**Error 狀態**:
```css
border-color: #dc3545;
box-shadow: 0 0 0 0.2rem rgba(220, 53, 69, 0.25);
```
- 下方顯示紅色錯誤訊息: `font-size: 12px`, `color: #dc3545`, `margin-top: 4px`

**Success 狀態**:
```css
border-color: #28a745;
```
- 右側顯示綠色勾勾圖示

**Disabled 狀態**:
```css
background-color: #e9ecef;
cursor: not-allowed;
opacity: 0.6;
```

### 4.2 標籤 (Labels)

- 字體大小: `14px`
- 字重: `500` (medium)
- 顏色: `#495057`
- 與輸入框間距: `8px`
- 必填欄位: 紅色星號 `*` 於標籤後

範例：
```html
<label>手機號碼 <span style="color: #dc3545">*</span></label>
<input type="tel" placeholder="請輸入手機號碼" />
```

### 4.3 按鈕嵌入輸入框

巴哈姆特的「取得驗證碼」按鈕設計：

- 輸入框使用 `position: relative`
- 按鈕 `position: absolute`, `right: 4px`, `top: 50%`, `transform: translateY(-50%)`
- 按鈕尺寸: `height: 32px` (小於輸入框高度)
- 按鈕樣式: 青綠色背景，白色文字
- 輸入框右側 padding 調整: `padding-right: 120px` (預留按鈕空間)

### 4.4 表單驗證模式

**即時驗證**:
- 失去焦點時 (onBlur) 驗證
- 顯示錯誤訊息於輸入框下方
- 輸入框邊框變紅

**送出驗證**:
- 點擊送出按鈕時
- 捲動至第一個錯誤欄位
- Focus 該欄位

**驗證訊息範例**:
- "此欄位為必填"
- "手機號碼格式不正確"
- "驗證碼須為 6 位數字"
- "序號格式錯誤"

### 4.5 表單布局

**垂直表單** (最常用):
```
[標籤]
[輸入框]
[錯誤訊息]

[標籤]
[輸入框]
[錯誤訊息]

[送出按鈕]
```
- 標籤與輸入框間距: `8px`
- 欄位之間間距: `20px`

**水平表單** (較少使用):
- 標籤寬度: `120px`, 右對齊
- 標籤與輸入框在同一行
- 使用場景: 設定頁面

### 4.6 輔助文字 (Help Text)

- 位置: 輸入框下方
- 字體大小: `12px`
- 顏色: `#6c757d`
- 用途: 提示輸入格式或補充說明

範例：
```html
<input type="text" />
<small class="form-text text-muted">
  序號格式: XXXX-XXXX-XXXX-XXXX
</small>
```

## 5. 卡片式內容布局

### 5.1 卡片基本結構

巴哈姆特使用**卡片 (Card)** 作為主要內容容器：

**外觀屬性**:
- 背景: 白色 `#ffffff`
- 邊框: `1px solid #dee2e6` (選用，也可無邊框純陰影)
- 圓角: `8px`
- 陰影: `0 2px 8px rgba(0, 0, 0, 0.1)`
- Hover 陰影: `0 4px 16px rgba(0, 0, 0, 0.15)` (升起效果)

### 5.2 卡片內部結構

**標準卡片組成**:
```
┌─────────────────────────────┐
│   [圖片區域]                  │ ← Card Image (可選)
├─────────────────────────────┤
│   [標題]                     │ ← Card Header
│   [描述文字]                 │ ← Card Body
│   [標籤 Tag1] [Tag2]         │
├─────────────────────────────┤
│   [按鈕] [連結]               │ ← Card Footer
└─────────────────────────────┘
```

**Padding 設定**:
- Card Body: `20px` (桌面), `16px` (手機)
- Card Header: `16px 20px`
- Card Footer: `12px 20px`

### 5.3 序號卡片設計

觀察到的序號兌換卡片特色：

**布局**:
- 左側: 遊戲圖片 (寬度 `120px`, 高度 `160px`, `object-fit: cover`)
- 右側: 序號資訊
  - 遊戲名稱 (字體: `16px`, `font-weight: 600`)
  - 序號內容 (字體: `14px`, 等寬字體 `monospace`)
  - 有效期限 (字體: `12px`, 灰色)
  - 狀態標籤 (未使用/已使用/已過期)

**狀態標籤**:
- 未使用: 綠色背景 `#d4edda`, 綠色文字 `#155724`
- 已使用: 灰色背景 `#e9ecef`, 灰色文字 `#6c757d`
- 已過期: 紅色背景 `#f8d7da`, 紅色文字 `#721c24`
- Padding: `4px 12px`
- 圓角: `12px` (膠囊形狀)

**操作按鈕**:
- 位置: 卡片右下角
- 樣式: 青綠色文字按鈕 "立即兌換"
- Hover: 加深顏色 + 下底線

### 5.4 卡片網格布局

**桌面 (≥1200px)**:
- 每行 4 張卡片
- 間距: `24px`
- CSS Grid:
  ```css
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  gap: 24px;
  ```

**平板 (768px - 1199px)**:
- 每行 3 張卡片
- 間距: `20px`

**手機 (<768px)**:
- 每行 1 張卡片
- 間距: `16px`

### 5.5 空狀態卡片

當沒有內容時的顯示：

- 圖示: 灰色大圖示 (如 📭)
- 文字: "目前沒有序號" (灰色，居中)
- 字體大小: `16px`
- 顏色: `#6c757d`
- Padding: `60px 20px`

## 6. 身份驗證流程

### 6.1 登入流程設計

巴哈姆特採用**手機號碼 + 簡訊驗證碼**的無密碼登入方式：

**步驟拆解**:

**步驟 1: 輸入手機號碼**
- 標題: "登入巴哈姆特"
- 輸入框: 電話號碼格式 (placeholder: "09XXXXXXXX")
- 按鈕: "取得驗證碼" (青綠色)
- 輔助文字: "我們將發送驗證碼至您的手機"

**步驟 2: 輸入驗證碼**
- 輸入框自動 focus
- 6 位數字輸入 (可拆分為 6 個單獨輸入框)
- 範例畫面顯示: `712345`
- 倒數計時: "60 秒後可重新發送" (倒數中為灰色，可用時變青綠色)
- 輸入完成後自動送出 (可選)

**步驟 3: 驗證成功**
- 顯示綠色勾勾 ✓
- 訊息: "登入成功"
- 自動關閉 Modal
- 畫面更新: 顯示用戶頭像與名稱

**錯誤處理**:
- "手機號碼格式不正確"
- "驗證碼錯誤，請重新輸入"
- "驗證碼已過期，請重新取得"
- "發送過於頻繁，請稍後再試"

### 6.2 驗證碼輸入框設計

**選項 A: 單一輸入框**
- 寬度: `100%`
- 字體: 等寬字體 `monospace`
- 文字對齊: 居中
- 字體大小: `24px`
- 字母間距: `0.5em`

**選項 B: 分離式輸入框** (巴哈姆特使用)
- 6 個獨立輸入框
- 每個寬度: `48px`
- 高度: `56px`
- 間距: `12px`
- 只接受數字
- 自動跳至下一格

CSS 範例：
```css
.code-input {
  width: 48px;
  height: 56px;
  font-size: 24px;
  text-align: center;
  border: 2px solid #ced4da;
  border-radius: 8px;
}

.code-input:focus {
  border-color: #17a2b8;
  box-shadow: 0 0 0 0.2rem rgba(23, 162, 184, 0.25);
}
```

### 6.3 倒數計時按鈕

「取得驗證碼」按鈕的狀態機制：

**初始狀態**:
- 文字: "取得驗證碼"
- 可點擊
- 青綠色背景

**發送中狀態**:
- 文字: "發送中..."
- 禁用
- Loading spinner

**倒數中狀態**:
- 文字: "60 秒後可重新發送" → "59 秒後..." → ... → "1 秒後..."
- 禁用
- 灰色背景

**可重發狀態**:

## 17. 陰影與層次

### 17.1 陰影系統

| 層級 | 陰影值 | 用途 |
|------|--------|------|
| 0 | none | 無陰影 |
| 1 | 0 1px 2px rgba(0,0,0,0.05) | 極淺陰影 |

| 4 | 0 8px 16px rgba(0,0,0,0.15) | 深陰影 (Modal) |
| 5 | 0 16px 32px rgba(0,0,0,0.2) | 超深陰影 (Dropdown) |

### 17.2 Z-index 層級

| 層級 | 數值 | 用途 |
|------|------|------|
| Base | 1 | 一般內容 |
| Dropdown | 1000 | 下拉選單 |
| Sticky | 1020 | 固定元素 |
| Fixed | 1030 | 頂部導航 |
| Modal Backdrop | 1040 | Modal 遮罩 |
| Modal | 1050 | Modal 對話框 |
| Popover | 1060 | Popover |
| Tooltip | 1070 | Tooltip |

### 17.3 陰影使用原則

1. **卡片靜止**: 使用層級 2 陰影
2. **卡片 Hover**: 提升至層級 3，配合 `translateY(-2px)`
3. **Modal**: 使用層級 4，確保與背景分離
4. **Dropdown**: 使用層級 5，強調懸浮感
5. **按鈕**: 預設無陰影，Hover 時加上層級 1-2 陰影

- 遵循視覺順序由上至下、由左至右
- 跳過隱藏內容 (`tabindex="-1"`)
- Modal 開啟時 focus trap

**Focus 樣式**:
```css
*:focus-visible {
  outline: 2px solid #17a2b8;
  outline-offset: 2px;
}
```

**快捷鍵**:
- `Esc`: 關閉 Modal/Dropdown
- `Enter`: 確認/送出
- `/`: Focus 搜尋框

### 19.2 螢幕閱讀器

**語意化 HTML**:
- 使用 `<nav>`, `<main>`, `<aside>`, `<footer>`
- 使用 `<button>` 而非 `<div onclick>`
- 使用 `<label>` 標示表單欄位

**ARIA 屬性**:
```html
<button aria-label="關閉對話框">
  <i class="bi bi-x"></i>
</button>

<div role="alert" aria-live="polite">
  操作成功
</div>

<button aria-expanded="false" aria-controls="dropdown">
  選單
</button>
```

### 19.3 顏色對比

**WCAG AA 標準**:
- 正常文字: 對比度 ≥ 4.5:1
- 大文字 (≥18px): 對比度 ≥ 3:1
- 巴哈姆特主色 `#17a2b8` 在白底上: 對比度 4.57:1 ✓

### 19.4 錯誤訊息

**不只依賴顏色**:
- 紅色邊框 + 錯誤圖示 (✗)
- 紅色文字 + 清楚的錯誤訊息

## 20. 設計原則總結

### 20.1 核心設計原則

1. **簡潔優先**: 白色背景 + 青綠色點綴，避免視覺雜亂
2. **一致性**: 統一的間距、圓角、陰影系統
3. **響應式**: Mobile-first，所有介面支援各種裝置
4. **即時反饋**: Hover、Focus、Loading 狀態清晰
5. **無密碼登入**: 手機 + 簡訊驗證，降低使用門檻
6. **Modal 優先**: 關鍵操作使用 Modal，減少頁面跳轉
7. **卡片化內容**: 所有內容以卡片呈現，結構清晰
8. **清晰層級**: 標題、正文、輔助文字層次分明
9. **輔助功能**: 鍵盤導航、螢幕閱讀器支援完善
10. **性能優先**: 動畫流暢但輕量，避免過度動畫

### 20.2 視覺識別重點

**最具辨識度的元素**:
1. **青綠色頂部導航**: `#17a2b8` 貫穿所有頁面
2. **手機驗證登入**: 無密碼設計，6 位數驗證碼
3. **卡片式布局**: 白色卡片 + 淺陰影
4. **Modal 確認流程**: 所有關鍵操作都經過 Modal 二次確認
5. **極簡配色**: 白 + 灰 + 青綠，非常克制
6. **清晰按鈕**: 主色按鈕 vs 灰色取消按鈕，對比明顯
7. **通知徽章**: 紅色數字徽章於鈴鐺右上角
8. **信箱三欄式**: 側邊欄 + 列表 + 內容的經典布局
9. **序號兌換**: 多步驟確認流程，避免誤操作
10. **Bootstrap 風格**: 大量使用 Bootstrap 組件與樣式

### 20.3 實現優先級建議

**Phase 1 - 基礎設施** (必須):
- 青綠色主題配色系統
- Bootstrap 5.3.3 引入
- 頂部導航列 (固定 56px)
- 容器與間距系統
- 按鈕與表單基礎樣式

**Phase 2 - 核心組件** (高優先):
- Modal 系統 (標準/確認/成功)
- 卡片組件與網格布局
- Toast 通知系統
- 表單驗證樣式
- Loading 與 Disabled 狀態

**Phase 3 - 進階功能** (中優先):
- 手機驗證登入流程
- 通知下拉面板
- 信箱系統 (如需要)
- 序號兌換系統 (如需要)
- 響應式導航與側邊欄

**Phase 4 - 優化** (低優先):
- 動畫與過渡效果
- Skeleton Loading
- 空狀態設計
- 輔助功能優化
- 效能優化
